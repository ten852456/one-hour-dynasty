# Smart Contracts

This directory contains all Solidity smart contracts for the One Hour Dynasty game.

## Contract Structure

- `WuxiaToken.sol` - ERC-20 token with burn functionality
- `ItemStore.sol` - In-game item store
- `GameResultsRecorder.sol` - Game results and ERC-8004 integration
- `Staking.sol` - WUXIA staking for priority queue
- `mocks/` - Mock contracts for testing

## Development

All contracts use Solidity ^0.8.20 with OpenZeppelin libraries.
