## Decision Framework

### During Meeting, Use This Process:

1. **Present Finding** → "Agent identified X as critical issue"
2. **Discuss Impact** → "If we don't fix this, Y happens"
3. **Evaluate Effort** → "This takes Z effort"
4. **Make Decision** → "Fix now / Fix later / Accept as-is"

### Priority Matrix

```
Impact vs Effort:

High Impact, Low Effort    → DO FIRST
High Impact, High Effort   → PLAN
Low Impact, Low Effort    → MAYBE
Low Impact, High Effort   → SKIP
```
